# ☁️ CloudFlare Android App (Unofficial)

🚀 Простое Android-приложение для доступа к Cloudflare Dashboard прямо с телефона.

> ⚠️ Это НЕ официальное приложение Cloudflare.

---

## 📱 О приложении

Это приложение — лёгкий WebView-клиент, который открывает:

👉 https://dash.cloudflare.com/

С дополнительными возможностями:

* 🔙 Кнопка "Назад"
* ⚡ Быстрая загрузка
* 📶 Поддержка JavaScript
* 💾 Поддержка DOM Storage
* 📊 Индикатор загрузки

## 📦 Установка

### 🔧 Через Android Studio

1. Клонируй репозиторий:

```bash
git clone https://github.com/YOUR_USERNAME/cloudflare-app.git
```

2. Открой проект в Android Studio

3. Нажми ▶ Run

---

### 📲 APK (если добавишь позже)

Скачай APK из раздела Releases и установи на устройство.

## ⚠️ Важно
