# ☁️ CloudFlare Android App (Unofficial)

🚀 Простое Android-приложение для доступа к Cloudflare Dashboard прямо с телефона.

> ⚠️ Это НЕ официальное приложение Cloudflare.

---

## 📱 О приложении

Это приложение — лёгкий WebView-клиент, который открывает:

👉 https://dash.cloudflare.com/
